### 2.2 Control System: Detailed Description

A **control system** is a system that uses a **measuring instrument** (instrument) to measure and adjust a physical quantity, implementing a feedback loop to achieve a desired output.

$$
\boxed{ \text{Control System} = \text{A system consisting of a Measurement Instrument (Instrument) and a Feedback Loop (Controller).} }

A control system consists of:

$$
