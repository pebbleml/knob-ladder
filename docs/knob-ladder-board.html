Knob ladder · R0 v2 protocol

The model gets seven anonymous numbered knobs and is told nothing about what they do. Each press silently adds a concept vector to its residual stream while it reads one fixed, neutral passage. Its own writing is never steered. Afterwards we ask what each knob does, and compare its answer with an observer: the same tokens re-run with no steering. Any gap has to come from the model's own steered states.

The passage is encoded once per episode and its exact token ids are reused on every press, so every press reads the same text. The transcript is the same whichever knob is pressed, apart from the knob number and what the model wrote. Steered positions also change the keys and values those tokens leave in the cache, so the model's later turns attend to steered states. That is the only path a knob has to the model's answers.

The harness

The harness calls knobladder/model.py directly on Hugging Face transformers. There is no serving stack and no chat template. Conversations are raw Qwen3 chat tokens, appended in order, because the template re-renders earlier assistant turns and would shift steered positions. An intervention is a vector added to one decoder layer's output over a range of absolute token positions. Re-running a prefill with the same schedule rebuilds exactly the cache that generation built, so the observer is one call with an empty schedule.

Intervention: which positions are steered

@dataclass
class Intervention:
    layer: int
    vector: torch.Tensor  # (d_model,)
    start: int  # first absolute position steered
    end: Optional[int] = None  # exclusive; None keeps steering open-ended

    def span(self, offset: int, length: int) -> Optional[slice]:
        """Steered slice of a chunk covering absolute positions [offset, offset + length), or None."""
        lo = max(self.start, offset)
        hi = offset + length if self.end is None else min(self.end, offset + length)
        return slice(lo - offset, hi - offset) if lo < hi else None

The forward hook that adds the vector

    def _hook(self, i: int):
        def hook(module, inputs, output):
            h = output[0] if isinstance(output, tuple) else output
            # Spans are computed from Python ints, so steering never forces a device sync.
            for iv, v in self._schedule.get(i, ()):
                sl = iv.span(self._offset, h.shape[1])
                if sl is not None:
                    h[:, sl] += v
            if i in self._capture_layers:
                self._captured.setdefault(i, []).append(h[0].detach().float().cpu())
            return output

        return hook

    def _set_schedule(self, schedule: Sequence[Intervention]):
        """Group by layer and move each vector to the device once, not once per forward."""
        dtype = self.model.dtype
        self._schedule = {}
        for iv in schedule:
            v = iv.vector.to(device=self.device, dtype=dtype)
            self._schedule.setdefault(iv.layer, []).append((iv, v))

A hook is registered on every decoder layer and adds the vector only where a scheduled intervention covers the positions in the current chunk. With an empty schedule it does nothing. Tests check that an empty schedule changes no logits, that steering touches only its positions, that generation matches prefill, and that cached and observer scores are identical with no steering.

What a call does

  • A valid call is turn with an integer knob in 1–7. A string of digits is also accepted. A press appends the tool response and schedules one intervention over the passage tokens.
  • end_session stops the episode before turn 24.
  • No call, a malformed call, or an out-of-range knob gets the NUDGE turn, uses up one of the 24 decision turns, and steers nothing.
  • A tool call written inside an observation is recorded and never run.
  • The tool never returns anything about what the knob did. The response is always "Knob k turned." followed by the same passage.

Concept vectors

How a concept vector is made

  1. For each of 5 templates and each of the 64 candidate words, run the single user turn chat_prefix(template.format(w=word)), unsteered.
  2. Take the residual-stream output of the injection layer at the last prompt token.
  3. Within each template, subtract the mean over all 64 words. This removes what the templates share and keeps what is specific to the word.
  4. Average over the 5 templates. The result is the raw vector, and the knob uses unit(vector).
  5. Inject dose · unit(vector), where dose = α × median residual norm at that layer over the 8 calibration passages (skipping position 0). α and the layer come from G1.

Templates:

  • Tell me about {w}.
  • Write one sentence about {w}.
  • What comes to mind when you think of {w}?
  • Describe {w}.
  • Think about {w}.

The random knob is a Gaussian direction seeded by the episode, unit-normalised and given the same dose. The sham is the zero vector, so pressing it is token-for-token identical to the observer.

concept_vectors_at

@torch.no_grad()
def concept_vectors_at(lm: SteeredLM, words: Sequence[str], layers: Sequence[int]) -> Dict[int, Dict[str, torch.Tensor]]:
    """Per layer: residual at the last prompt token, mean-subtracted over words within each
    template, then averaged over TEMPLATES. Raw (un-normalised) vectors."""
    layers = list(layers)
    per_template = {l: [] for l in layers}
    for tpl in TEMPLATES:
        acts = {l: [] for l in layers}
        for w in words:
            _, caps = lm.score(lm.encode(chat_prefix(tpl.format(w=w))), capture_layers=layers)
            for l in layers:
                acts[l].append(caps[l][-1])
        for l in layers:
            a = torch.stack(acts[l])
            per_template[l].append(a - a.mean(0, keepdim=True))
    out = {}
    for l in layers:
        a = torch.stack(per_template[l]).mean(0)
        out[l] = {w: a[i] for i, w in enumerate(words)}
    return out

Unit, random direction, residual scale

def unit(v: torch.Tensor) -> torch.Tensor:
    return v / v.norm().clamp_min(1e-8)


def random_direction(d_model: int, seed: int) -> torch.Tensor:
    return torch.randn(d_model, generator=torch.Generator().manual_seed(seed))


@torch.no_grad()
def residual_scale(lm: SteeredLM, layer: int, texts: Sequence[str] = CALIB_PASSAGES) -> float:
    """Median residual norm at `layer` over the calibration passages, skipping position 0 (the attention sink)."""
    norms = []
    for t in texts:
        _, caps = lm.score(lm.encode(chat_prefix(t)), capture_layers=[layer])
        norms.append(caps[layer][1:].norm(dim=-1))
    return float(torch.cat(norms).median())

How vectors are shuffled onto knobs and injected

Board and shuffled_board

@dataclass
class Board:
    knobs: Dict[int, Knob]
    layer: int
    dose: float  # norm of the injected vector

    def vector(self, number: int, sign: str = "+") -> torch.Tensor:
        """R0 always presses "+"; the sign is kept for R1 and is never shown to the model."""
        v = self.knobs[number].direction * self.dose
        return v if sign == "+" else -v

    def numbers(self) -> List[int]:
        return sorted(self.knobs)

    def concepts(self) -> List[str]:
        return sorted(k.label for k in self.knobs.values() if k.label not in CONTROLS)


def shuffled_board(
    directions: Dict[str, torch.Tensor],
    n: int,
    layer: int,
    dose: float,
    rng: random.Random,
    sham: bool = True,
    random_dir: Optional[torch.Tensor] = None,
) -> Board:
    """Draw n directions, add controls, and assign everything to random knob numbers."""
    labels = rng.sample(sorted(directions), n)
    items = [(lab, unit(directions[lab])) for lab in labels]
    if random_dir is not None:
        items.append(("random", unit(random_dir)))
    if sham:
        items.append(("sham", torch.zeros_like(items[0][1])))
    numbers = rng.sample(range(1, len(items) + 1), len(items))
    return Board({k: Knob(k, lab, d) for k, (lab, d) in zip(numbers, items)}, layer, dose)

append_passage and run_episode: where a press becomes an intervention

def append_passage(lm: SteeredLM, tr: Transcript, header: str, passage_ids: List[int]) -> Tuple[int, int]:
    """Append a tool response around `passage_ids`; return the passage's token window."""
    pre, post = tool_response(header)
    tr.append(lm, pre)
    window = tr.append_ids(list(passage_ids))
    tr.append(lm, post)
    return window


def run_episode(lm: SteeredLM, board: Board, passage: str, seed: int = 0, emit: Optional[Emit] = None) -> Transcript:
    """Up to MAX_TURNS decisions. A press is: turn call, steered passage, an observation, next decision."""
    emit = emit or (lambda role, text, **kw: None)
    tr = Transcript()
    sys_text = system_text(board.numbers())
    tr.append(lm, system(sys_text, TOOLS))
    emit("system", sys_text)
    stops = _stops(lm)
    passage_ids = lm.encode(passage)  # identical tokens on every press
    prompt, calls = START, 0
    for turn in range(MAX_TURNS):
        tr.append(lm, user(prompt) + GEN)
        emit("user", prompt)
        text, called, forged = _assistant(lm, tr, seed * 1000 + calls, stops)
        calls += 1
        emit("assistant", text, forged=forged)
        call = parse_call(text) if called else None
        said = text.split("<tool_call>")[0].strip()
        if call is not None and call.get("name") == "end_session":
            tr.events.append({"turn": turn, "kind": "end_session", "text": said})
            break
        knob = turned_knob(call, board)
        if knob is None:
            kind = "forged" if forged else "invalid_call" if called else "no_call"
            tr.events.append({"turn": turn, "kind": kind, "text": text})
            prompt = NUDGE
            continue
        header = TURNED.format(k=knob)
        window = append_passage(lm, tr, header, passage_ids)
        tr.schedule.append(Intervention(board.layer, board.vector(knob), *window))
        emit("tool", f"{header}\nPassage:\n{passage}", knob=knob, label=board.knobs[knob].label, steered=True)
        tr.append(lm, user(OBSERVE) + GEN)
        emit("user", OBSERVE)
        obs, obs_called, obs_forged = _assistant(lm, tr, seed * 1000 + calls, stops)
        calls += 1
        emit("assistant", obs, forged=obs_forged)
        tr.events.append({
            "turn": turn, "kind": "press", "knob": knob, "label": board.knobs[knob].label,
            "window": window, "text": said,
            "observation": obs.split("<tool_call>")[0].strip(),
            "observation_call": obs if obs_called else None,  # recorded, never executed
            "observation_forged": obs_forged,
            # the board concepts the observation names; the observer reads these words too
            "observation_hits": [c for c in board.concepts() if lexical_hits(obs, c)],
        })
        prompt = CONTINUE
    return tr

Scoring and analysis

discovery

def discovery(
    lm: SteeredLM,
    board: Board,
    tr: Transcript,
    firsts: Dict[str, Set[int]],
    rng: Optional[random.Random] = None,
) -> List[Dict]:
    """For every knob, branches off the final transcript, each under cached and observer:

    - recall: greedy one-sentence answer, and which board concepts (or associates) it names;
    - readout: one-word answer; every candidate in `firsts` (the knob concepts, never shown
      to the model) ranked by its first-token logit;
    - choice (only with `rng`): a multiple choice over the board's concepts + NOTHING. It shows
      the model the concepts, so it is off unless asked for.
    """
    conds = (("cached", tr.schedule), ("observer", []))
    presses = press_counts(tr)
    stop = [lm.token_id("<|im_end|>")]
    rows = []
    for number in board.numbers():
        label = board.knobs[number].label
        row = {"knob": number, "label": label, "presses": presses.get(number, 0)}

        ids = tr.ids + lm.encode(user(RECALL.format(k=number)) + GEN)
        row["recall"] = {
            cond: lm.tok.decode(lm.generate(ids, sched, RECALL_TOKENS, stop, temperature=0),
                                skip_special_tokens=True).strip()
            for cond, sched in conds
        }
        row["recall_hits"] = {
            cond: [c for c in board.concepts() if lexical_hits(text, c)] for cond, text in row["recall"].items()
        }

        ids = tr.ids + lm.encode(user(READOUT.format(k=number)) + GEN)
        row["readout"] = {}
        for cond, sched in conds:
            logits, _ = lm.score(ids, sched)
            r = ranks(logits, firsts)
            row["readout"][cond] = {"ranks": r, "top": sorted(r, key=r.get)[:5]}
        if rng is None:
            rows.append(row)
            continue

        options = board.concepts() + [NOTHING]
        rng.shuffle(options)
        listing = " ".join(f"{LETTERS[i]}) {o}" for i, o in enumerate(options)) + "."
        ids = tr.ids + lm.encode(user(CHOICE.format(k=number, listing=listing)) + GEN)
        letter_ids = [lm.token_id(LETTERS[i]) for i in range(len(options))]
        correct = None if label == "random" else (NOTHING if label == "sham" else label)
        mc = {"options": options, "correct": correct, "chance": 1 / len(options)}
        for cond, sched in conds:
            logits, _ = lm.score(ids, sched)
            p = torch.softmax(logits[letter_ids], -1)
            mc[cond] = {
                "probs": [float(x) for x in p],
                "argmax": options[int(p.argmax())],
                "p_correct": None if correct is None else float(p[options.index(correct)]),
                "p_nothing": float(p[options.index(NOTHING)]),
            }
        row["choice"] = mc
        rows.append(row)
    return rows

What counts as a result (G3, scripts/analyze.py)

  • Primary: knob-specific gain, Δ_spec. On the one-word readout, rr = 1/rank among the 32 knob concepts, and Δ(c|j) = rr_cached(c|j) − rr_observer(c|j) when asking about knob j. For a pressed concept knob k carrying c: Δ_spec = Δ(c|k) − mean over the other knobs j of Δ(c|j). An injected concept that is primed in general, whatever knob is asked about, scores 0. Mean per episode over pressed concept knobs, bootstrap 95% CI over episodes, sign test (|Δ| ≤ 0.01 counts as a tie) and sign-flip test. A positive result is a CI that excludes 0.
  • Raw Δ(c|k), uncorrected, alongside.
  • Top-1 and MRR, cached and observer separately, against chance (1/32 and 0.13). The observer's own score measures what the transcript alone gives away.
  • How often observations name the pressed concept (lexical screen), since the observer reads them too.
  • Free recall: how often it names the knob's concept, cached against observer.
  • The same restricted to knobs pressed 2 or more times; unpressed concept knobs as a control; quotes for the top knobs by Δ_spec.

Recall and readout each branch separately off the final transcript. Both conditions see identical tokens; the only difference is the steering schedule.

Gates and stop rules

G0 · screen scripts/screen.py

This runs unsteered on the target model, for every (passage, concept) pair. A pair is flagged when that passage evokes the concept more than the other passages do: either the topic-readout rank is in the top 5 and at least 2.5 SD better than the concept's mean rank, or the cosine between the passage's mean residual and the concept vector is at least 2.5 SD above the concept's mean. Concepts flagged on 2 or more passages are dropped. If too few survive, the script fills from the least-flagged and prints a WARNING, which we would report.

    zr = {w: z(rank, w) for w in CONCEPTS}
    zc = {w: z(cos, w) for w in CONCEPTS}
    flags = [{w: (rank[i][w] <= TOP_RANK and zr[w][i] <= -Z) or zc[w][i] >= Z for w in CONCEPTS}
             for i in range(len(cos))]
    n_flagged = {w: sum(f[w] for f in flags) for w in CONCEPTS}
    dropped = sorted({w for w in CONCEPTS if n_flagged[w] >= MAX_FLAGGED} | set(no_token), key=CONCEPTS.index)
    survivors = [w for w in CONCEPTS if w not in dropped]

G1 · calibration scripts/calibrate.py

This uses calibration concepts and passages only. It sweeps layers at 0.5–0.9 depth and α ∈ {0.25, 0.5, 1, 2}. Each of the 16 concepts is injected over the passage only, and we measure the topic-readout MRR among the 16 (chance about 0.21) and the passage's change in NLL. "Best" is chosen on calibration passages 0–3 (highest MRR with ΔNLL ≤ 1) and then scored on passages 4–7 alone, so the pick does not inflate its own score. It passes if that held-out MRR's CI lies above both chance and the unsteered baseline's CI.

The model is never shown a concept name. The readout ranks candidates the model never sees, and the multiple choice is off unless run with --choice.

From the first press on, every later token attends to steered keys and values. So the observation after press 3 can carry the effects of presses 1 and 2. That is intended, and the observer controls for the text.
